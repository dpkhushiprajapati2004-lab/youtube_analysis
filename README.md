# YouTube Dashboard (Power BI)

## Overview
An interactive Power BI dashboard that analyzes YouTube channels by category, subscribers, video count, average views per video and channel start year.


## Features
- KPI cards showing total channels and subscribers
- Category slicer to filter the whole dashboard
- Scatter plots: video count vs subscribers, and start year vs subscribers
- Donut chart showing channel count by category
- Bar chart of average views per video
- Channel list for quick lookup

## Tools Used
Power BI


## Key Insights
- Most Comedy channels have a low video count but still cross 10M subscribers, so posting more videos does not guarantee more subscribers
- Average views per video for the Comedy category is about 14M
